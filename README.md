# Vinith — Premium Editorial Portfolio

A responsive, typography-led personal portfolio built with plain HTML, CSS and JavaScript. The visual direction is premium editorial: near-black backgrounds, warm gold accents, expressive serif headlines and restrained motion. No profile photo is used.

## Project files

- `index.html` — page content and section structure
- `style.css` — visual design, responsive layouts and motion
- `script.js` — mobile navigation, current year and reveal effects
- `assets/` — place your resume here

## Run locally

**Option 1 — VS Code Live Server**
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

**Option 2 — Python**
1. Open a terminal in the project folder.
2. Run `python -m http.server 8000`.
3. Visit `http://localhost:8000`.

## Personalize before publishing

1. In `index.html`, replace the email `your.email@example.com` with your real email address.
2. Update the LinkedIn, Behance and GitHub links. Remove any platform you do not use.
3. Replace the sample experience entries with your real company, role, dates and achievements.
4. Replace the two concept projects with real work. Add project links, screenshots, your contribution and outcomes. Do not present the starter concepts as client work.
5. Add your resume as `assets/Vinith-Resume.pdf`, or update the resume link to match your file name.
6. Review the page on mobile and desktop, and test every link.

## Deploy

You can publish this static site using GitHub Pages, Netlify or Vercel. For Netlify, drag the extracted project folder into the deploy area. For GitHub Pages, push the files to a repository and enable Pages in the repository settings.

## Notes

- The contact link opens the visitor's default email application using `mailto:`; it is not a server-backed contact form.
- Google Fonts are loaded online. If offline font loading is unavailable, the browser falls back to system fonts.
- The website contains no profile-photo placeholder by design; the hero identity is typography-led.
